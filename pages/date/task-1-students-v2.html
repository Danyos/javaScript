# Անուն Մասնագիտություն Սկիզբ Ավարտ Կարգավիճակ Տևողություն Ավարտից անցած (օր) Գործողություն

Օր․ 2010s, 2020s ... (քանակներ)

Ֆունկցիոնալ մաս (ինչ կա ներսում)

  • CRUD՝ add/edit/delete ուսանող, validation + toast հաղորդագրություններ
  • localStorage՝ պահում/վերականգնում, reset + seed տվյալներ
  • Date Filters՝ start/end range (YYYY-MM-DD)
  • Duration՝ հաշվվում է օր/ամիս/տարի (precise)
  • CSV Export՝ հենց ցուցադրված շարքերից
  • Edge-cases՝ endDate null, start > end, incomplete fields, empty lists
